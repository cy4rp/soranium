The P2PKH measurements below are retained as historical Arcade-acceptance
measurements. They are not measurements of block inclusion or mining
throughput. The earlier synthetic STAS measurements were removed when the
wallet path moved to the official DSTAS SDK.

Network: `ttn`
Fee setting: `FEE_PER_KB=1`

## Official DSTAS benchmark results

The official wallet benchmark used:

`STAS 3.0 spec v0.2.4 / engine Template STAS 3.1 (revision 0.0.11) via dxs-bsv-token-sdk 1.0.4 + patch`

The requested 2,000-output issue size returned Arcade HTTP 500
(`{ "error": "failed to submit" }`), as did 500 outputs. The 10,000 official
outputs were therefore issued as 100 sequential 100-output transactions; all
100 issue transactions and their contracts returned HTTP 202 with no
rejections. Per-transaction evidence is in
`/home/ubuntu/ttn/dstas-batches-100.json`.

| mode | pipeline | batch size | concurrency | workers | build TPS | broadcast TPS | end-to-end TPS | accepted / rejected | verification sample |
|---|---:|---:|---:|---:|---:|---:|---:|---:|---|
| Official DSTAS | true | 500 | 16 | 8 | 6.06 | 6.05 | 6.05 | 10,000 / 0 | `MINED=20` |
| Official DSTAS | false | 500 | 16 | 8 | 32.56 | 205.07 | 28.10 | 10,000 / 0 | `SEEN_MULTIPLE_NODES=16`, `SEEN_ON_NETWORK=4` |

The full JSON reports are appended to `/home/ubuntu/ttn/bench-results.md`.
The official SDK build is intentionally reported as measured; no benchmark-only
optimization bypasses the SDK path.

`broadcastTps` measures Arcade HTTP 202 acceptance, not block inclusion or
mining throughput. The legacy NOP-only pseudo-STAS outputs were excluded from
the official DSTAS wallet and benchmark results.
